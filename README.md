#  **Stock Market Volatility Detector**
An AI-powered tool that analyzes stock price volatility using **technical indicators** and **machine learning models**.

##  **Project Overview**
This project detects **high-volatility days** in stocks to support trading decisions.

### 🔹 **Features**
✅ Uses **RSI, MACD, ATR** to predict market trends  
✅ Balances dataset using **SMOTE** for better classification  
✅ Trains **Random Forest, SVM, and Gradient Boosting** with hyperparameter tuning  
✅ Visualizes stock movements with **candlestick charts using mplfinance**
